Curso 2026-2027

## Objetivo

Análisis de requisitos y diseño UML de un sistema
web para la detección y predicción de incidencias
en infraestructuras ferroviarias.

## Integrantes

Pendiente de completar.

## Organización

- `requisitos/`: requisitos funcionales y de dominio.
- `uml/`: diagramas de clases, paquetes y secuencias.
- `memoria/`: fuentes y figuras de la memoria final.
- `seguimiento/`: roles, decisiones y uso de IA.

## Planificación

- Semana 1: captura inicial de requisitos.
- Semana 2: especificación final y diseño UML inicial.
- Semanas 3 y 4: desarrollo y revisión de diagramas UML.

A partir de la semana 3 no se modifican los requisitos.
